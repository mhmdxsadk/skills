# Skills

Skills for planning and building digital products.

**Version: 0.2.0** (development draft). See the [changelog](CHANGELOG.md).

## product-development

Turn a raw product idea or problem into an implementation-ready specification: discovery, critical evaluation, scoping, requirements, UX, technical design, and a build plan. Depth adapts to the problem, the evidence, and the cost of a wrong decision.

## Install

```sh
npx skills add mhmdxsadk/skills --list
npx skills add mhmdxsadk/skills --skill product-development -g -a codex -a claude-code
```

## Usage

The skill is explicit-only. Invoke it by name, then describe the task:

- Codex: select `$product-development`
- Claude Code: start the message with `/product-development`

Example requests:

- "Help me decide whether this product idea is worth pursuing, then define what we should build."
- "We already have discovery notes. Help us identify gaps and turn them into a specification."
